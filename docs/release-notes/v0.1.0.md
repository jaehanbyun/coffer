# Coffer 0.1.0 Production Candidate Release Notes

- Promotion status: blocked
- Release status: not released
- Updated: 2026-07-28

## Scope

Coffer 0.1.0 is the first planned operator-local production candidate for the
OpenStack-native OCI Registry service. Its intended release surface includes
the Coffer API, token service, quota edge, authenticated reconciler,
unmodified CNCF Distribution data plane, OpenStackClient commands, Horizon
dashboard, Skyline Console pages, and the companion Kolla-Ansible role.

## Current Boundary

This is not a released or production-qualified version. The canonical Stage 6
ledger is fail-closed because the required official upstream Distribution,
Ceph Tentacle, and `oslo.messaging` release inputs are not
`candidate-qualified`. Consequently, immutable multi-architecture artifacts,
live RGW/Barbican SSE-KMS, maintenance-identity, data-protection,
observability, load/soak/fault, fresh Kolla multinode, and independent
operator-release evidence have not been accepted as one promotion
transaction.

The retained Horizon/Skyline preview and all local fixtures are excluded from
production evidence.

## Required Before Release

- Change `Promotion status` to `production-candidate` only after the first
  nine specialist results qualify against one immutable release revision.
- Record the exact signed source tag, image digests, SBOM, provenance,
  vulnerability attestations, support matrix, and upgrade compatibility.
- Complete the independent operator review, repository regression, secret
  scan, documentation checks, rollback ownership, and zero-residue audit.
- Recompile the source-bound operator-release result and require the canonical
  ledger to derive all ten gates passed and `production_candidate=true`.

Official Kolla or OpenStack upstream inclusion remains a later governance
phase and is not part of this release.
